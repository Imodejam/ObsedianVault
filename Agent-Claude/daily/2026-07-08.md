
## Nemi agentica (background) — Puntify
- SendAsync: task COMPLESSI ora postano il piano + creano NemiTask status="pending" e RITORNANO subito (no ExecuteComplex sincrono → niente timeout). Task SEMPLICI invariati (sincroni).
- NemiChatService.ProcessPendingTasksAsync: seleziona pending/planning/running-orfani, CLAIM atomico (status→running, bump retry solo su resume orfano), 1 task/shop per giro, esegue ExecuteRemainingSteps (posta ogni step in chat), chiude completed/failed + msg finale.
- NemiTaskResumeService: da one-shot a WORKER CONTINUO (delay 10s poi loop ogni 5s → ProcessPendingTasksAsync). Fail-safe try/catch.
- ExecuteRemainingSteps: troncamento OriginalRequest se >4000 char (2000+"…[troncato]"); posta risultato di ogni step nello storico.
- Endpoint GET /api/shop/{shopId}/ai/nemi/active-task {active,status,currentStep,totalSteps}. Client NemiActiveTaskAsync + DTO.
- UI AiAssistantFab.razor + AssistantAi.razor: polling ogni 3s (history+active-task), indicatore "Nemi sta lavorando… (passaggio X/N)" (key aifab_working, 10 lingue), stop su active=false o timeout 5min, dispose CTS.
- Build 0 errori. Restart sequenziale OK: server :8001 200, app-cat :8002 200, worker attivo nei log. NON committato/deployato.
