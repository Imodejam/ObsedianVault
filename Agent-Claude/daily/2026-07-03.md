# 2026-07-03

## Fix bug logout → rientro schermata scelta PV (msg Telegram 5127)
**Sintomo (simulatore iOS):** dopo il logout l'utente merchant rientrava subito in `merchant-shops` ("i miei PV") invece della schermata di login.

**Causa root:** i handler `SignOut()` di Merchant/Client/Operator facevano SPA-navigation a `/login` (`NavigateToRoute("login")`), che NON ricarica l'app → il client Supabase resta vivo in-memory. `SupabaseService.SignOut()` chiama `_client.Auth.SignOut()` dentro `try/catch{}`: se fallisce (rete, tipico nel simulatore) l'eccezione è inghiottita e `CurrentUser` (`=> _client.Auth.CurrentUser`) resta valorizzato. `Login.razor` OnInitializedAsync: il cookie è pulito quindi `cache==null`, ma poi controlla `Supabase.CurrentUser != null` → `RedirectBasedOnRole()` → per il merchant con profilo → `merchant-shops`.

**Fix:** `Navigation.NavigateToRoute("login", forceLoad: true)` nei 3 handler (Admin già usava `NavigateTo("/", forceLoad:true)`, per questo lì funzionava). Il full reload azzera tutto lo stato in-memory; cookie `punto_account` + localStorage `punto_supabase_session` + `authHelper.clearTokens` sono già puliti da `SignOut()`, quindi `LoadSession()` torna null → login pulito.

**File:** `Pages/Merchant/MerchantAccount.razor`, `Pages/Client/ClientAccount.razor`, `Pages/Operator/OperatorHome.razor`.
